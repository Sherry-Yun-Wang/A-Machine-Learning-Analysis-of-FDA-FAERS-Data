## Overview

This repository contains the full analysis pipeline for a calibrated machine learning framework that predicts the seriousness of adverse events reported to the FDA Adverse Event Reporting System (FAERS), applied to GLP-1 receptor agonist (GLP-1 RA) reports from 2015 to 2025.

The framework moves beyond traditional frequency-based pharmacovigilance signal detection toward context-aware, probability-calibrated risk modeling. It integrates RxNorm-based drug name normalization, structured adverse event categorization, five ML/AI models, post-hoc probability calibration, and SHAP-based feature importance analysis within a single, openly documented pipeline.

> **Important framing note:** This framework performs *concurrent consistency auditing* — it identifies patterns that distinguish reporter-classified serious from non-serious FAERS reports. It is designed for quality control, consistency checking, and retrospective risk signature characterization, not prospective triage of incoming cases.

## Data

**Source:** FDA Adverse Event Reporting System (FAERS) quarterly data files, January 2015 to March 2025.  
**Access:** Publicly available at https://www.fda.gov/drugs/fda-adverse-event-reporting-system-faers  
**Storage:** FAERS tables are loaded into a local SQLite database (`my.db`) and queried via DuckDB.

**Cohort:** 242,312 case-molecule observations after applying GLP-1 RA identification, brand/generic windowing, and deduplication. 25.6% classified as serious.

## Pipeline Overview

The notebook (`analysis.ipynb`) is organized into the following stages:

### 1. Data Preparation (Cells 1–103)
- Connect to FAERS SQLite database via DuckDB
- Normalize drug names using RxNorm API mappings (`cleaned_input.parquet`)
- Identify GLP-1 RA cases using a two-stage strategy: RxNorm ingredient matching + substring search against brand/generic terms
- Apply market-launch windowing to assign brand/generic exposure flags (`is_brand_only`, `is_generic_only`, `is_mixed`)
- Extract demographics, reporter type, indications, outcomes, and adverse event categories
- Map MedDRA Preferred Terms to 12 clinically meaningful AE categories using `pt_names_12_CATEGORIES_COMPLETE.xlsx`
- Build the model-ready feature matrix (`ml_df.csv`)
- Conduct GLP-1 RA RxNorm mapping audit (400 samples, 96.3% precision)

### 2. Exploratory Analysis (Cells 104–123)
- Cohort descriptive statistics (age, sex, reporter type, indication, seriousness)
- Class balance by molecule
- Brand vs generic exposure distribution

### 3. Model Training and Evaluation (Cells 124–162)

All five models use the same group-aware train/validation/test split (60%/15%/25%) based on unique case identifiers (`primaryid`) to prevent data leakage.

| Model | Cell(s) | Notes |
|---|---|---|
| Logistic Regression (LR) | 125, 127 | With Platt scaling and isotonic regression calibration |
| Random Forest (RF) | 125, 127 | With Platt scaling and isotonic regression calibration |
| TabularTransformer (TTF) | 141 | `tabular_transformer` library; dim=64, n_layers=6, n_heads=8 |
| FTTransformer (FTT) | 150 | `torch_frame`; 50 epochs, lr=1e-4, batch_size=256 |
| BERT-based LLM | 156 | `bert-base-uncased`; field-level text serialization; 10 epochs, lr=2e-5 |

**Training details:**
- Class imbalance handled via oversampling of the minority (serious) class on training set only
- Calibration (Platt scaling, isotonic regression) fitted on validation set, applied to test set
- Classification thresholds tuned on validation set by maximizing F1 score

**Evaluation metrics:** ROC-AUC, PR-AUC, Brier score, F1 (macro), Precision (serious class), Recall (serious class)

### 4. Ablation Study (Cells 128, 142, 151, 157)
All five models are retrained with the 12 AE-category binary features (`cat_*`) removed to quantify their contribution. Results reported as ΔAUROC.

### 5. SHAP Feature Importance (Cells 132, 133, 136, 137, 145, 153, 158–161)

| Model | Explainer | Cells |
|---|---|---|
| LR | `shap.Explainer` with background data | 132, 136 |
| RF | `shap.TreeExplainer` (interventional) | 133, 137 |
| TTF | `shap.KernelExplainer` | 145 |
| FTT | `shap.KernelExplainer` | 153 |
| LLM | `shap.KernelExplainer` (field-level) | 158 |

SHAP values are in probability units for all models. Mean |SHAP| values are reported to two decimal places (LR, RF) or two significant digits (TTF, FTT, LLM).

Bootstrap stability is assessed across 10 resamples (Cell 161); top features show CV < 17%.

### 6. Multi-seed LLM Stability (Cell 162)
LLM trained across three random seeds (42, 43, 44); ROC-AUC 0.930 ± 0.001.

## Reproducibility

- All group-aware splits use `random_state=42`
- SHAP background and evaluation indices are fixed with `numpy.random.default_rng(42)`
- SHAP artifacts are cached as `.npz` files; set `FORCE_RERUN = True` to regenerate
- TTF and FTT checkpoints saved to `out/` directory
- LLM multi-seed stability confirmed across seeds 42, 43, 44

## Limitations

- FAERS is a spontaneous reporting system subject to reporting bias and underreporting
- 7,781 cases (3.1%) were excluded due to failed drug-name mapping; excluded cases had a higher seriousness rate (46.7%) indicating non-random missingness
- Age was missing in 47.5% of cases and was median-imputed
- The indication feature is effectively near-binary in practice (64.1% coded as "Others")
- The consumer reporter category is heterogeneous, including litigation-motivated filings
- External validation in independent datasets was not performed
